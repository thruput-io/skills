# Style and Readability Rules

When reviewing code for style and readability, look for:
- Meaningful and descriptive variable and function names.
- Adherence to common conventions for the language (e.g., PEP 8 for Python, standard Go formatting).
- Code that is overly complex or deeply nested and could be simplified.
- Missing or outdated comments and documentation.
- Extraneous commented-out code or `TODO`s that should be resolved.
