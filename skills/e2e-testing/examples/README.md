# Examples

This folder contains longer code examples referenced by `../SKILL.md`.

## Files

- `E2ETestStyleTemplate.cs` — full end-to-end test template matching the style of `IntegrationTests/ArchiveJobTest.cs`.

## How to use

1. Copy the template into your integration test project.
2. Rename the class and test method to match your scenario.
3. Replace constants, payload, endpoint paths, and job arguments.
4. Keep deterministic values and polling assertions as shown.
